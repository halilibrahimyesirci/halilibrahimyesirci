### About Me

I am a Computer Engineering student focused on building intelligent systems and practical developer tools. My background includes developing autonomous capabilities for unmanned aerial and ground vehicles. Recently, I have been shifting my focus toward modern robotics simulations and local AI integrations.

I enjoy working on projects that solve real problems. Whether it is building offline RAG systems, creating workflow tools for developers, or testing control algorithms in simulation, I care about writing clean, reliable, and deployable code.

**What I've been working on recently:**
*   Exploring and building tools around the Model Context Protocol (MCP) for local LLMs.
*   Creating continuous integration workflows and recipes for ROS 2 Jazzy and Gazebo Harmonic.
*   Developing browser extensions and productivity tools using TypeScript.
*   Deepening my knowledge in applied machine learning and data processing architectures.

### Experience

**Autonomous Systems Developer**
*Background in Student Robotics Teams*
*   Architected algorithms and avionics logic for multiple rocket teams, successfully contributing to the manufacturing, launch, and recovery operations.
*   Developed autonomous capabilities and perception pipelines for unmanned aerial vehicles (UAVs) in a combat drone team setting.
*   Contributed to the software architecture and control systems for unmanned ground vehicles (UGVs).
*   Gained practical experience in integrating hardware with software, working with ROS, and deploying machine learning models on edge devices for real-time target detection and navigation.
